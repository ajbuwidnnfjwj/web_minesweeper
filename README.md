# 지뢰찾기

`dist/index.html`을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 빌드가 필요 없습니다. 웹 서버에는 `dist` 폴더의 파일을 함께 올리세요.

- 초급: 9 × 9, 지뢰 10개 / 중급: 16 × 16, 지뢰 40개 / 고급: 30 × 16, 지뢰 99개
- 클릭·터치: 칸 열기 / 오른쪽 클릭: 깃발 표시·해제
- 열린 숫자 좌클릭: 주변 깃발 수가 숫자와 같으면 깃발 없는 주변 칸을 한 번에 엽니다. 깃발 위치가 틀리면 지뢰가 열려 패배합니다. 깃발 모드를 끈 상태의 터치 및 Enter·Space 키로도 사용할 수 있습니다. 우클릭과 F 키는 깃발 표시·해제에 사용합니다.
- 모바일: 깃발 모드를 켜고 칸을 터치
- 키보드: Tab으로 칸 진입, 방향키로 이동, Enter·Space로 열기, F로 깃발 표시
- 첫 클릭과 주변 8칸은 안전하며, 빈 영역은 자동으로 열립니다.
- 지뢰가 없는 모든 칸을 열면 승리합니다.
- 새 게임 또는 난이도 선택으로 초기화합니다.

게임 규칙 검증: `node --test tests/game.test.cjs`
